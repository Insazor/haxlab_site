# HAX Lab Site

정적 연구실 홈페이지입니다. Tailwind CSS 기반 커스텀 UI와 `anime.js` 애니메이션을 사용합니다.

## Pages

- `index.html`, `home.html`
- `news.html`
- `people.html`
- `projects.html`
- `research.html`
- `publications.html`
- `awards.html`
- `gallery.html`
- `courses.html`

## Assets

- 스타일: `assets/css/source.css` -> `assets/css/site.css`
- 스크립트: `assets/js/site.js`
- 이미지: `assets/mirror/`

## Build

- 의존성 설치: `npm install`
- CSS 및 vendor 갱신: `npm run build`
